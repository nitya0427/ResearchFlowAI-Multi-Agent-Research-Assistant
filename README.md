# ResearchFlowAI-Multi-Agent-Research-Assistant
A production-grade multi-agent AI research assistant built with LangChain, Gemini 2.5 Flash, Tavily Search API, BeautifulSoup, and Streamlit. It autonomously searches, analyzes, synthesizes, and reviews information to generate citation-backed research reports.
